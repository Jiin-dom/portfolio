# JD Paloma — Glyphfield Portfolio

Typography-led portfolio for Jeanne Dominique Paloma (full-stack developer, UI/UX focus).

## Stack

Next.js 16 (App Router) · React 19 · TypeScript · Tailwind CSS v4 · GSAP · Lenis · Motion · React Three Fiber / drei

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

```bash
npm run lint
npm run build
npm start
```

## Content

All factual content lives in [`src/lib/content.ts`](src/lib/content.ts). Project screenshots are under `public/images/`. The previous Bootstrap single-page site is archived in `_legacy/`.

# JD Paloma — Portfolio

Awwwards-oriented personal portfolio for **Jeanne Dominique Paloma** (full-stack developer, UI/UX focus).

## Stack

- Next.js (App Router) + TypeScript
- Tailwind CSS v4
- Motion
- GSAP + ScrollTrigger
- Lenis
- React Three Fiber + drei

## Develop

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Build

```bash
npm run build
npm start
```

## Deploy

Vercel-ready. Connect the repo and deploy the root app (no special config required).

## Content

Factual content lives in `src/lib/content.ts`. Brand assets are under `public/images` and `public/fonts` (Satoshi). Legacy Bootstrap site is archived in `_legacy/` for reference only.

## Design docs

- `PRODUCT.md` — product truth
- `DESIGN.md` — visual system for the new world
